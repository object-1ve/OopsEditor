# Oops Editor

一款跨平台桌面代码编辑器，基于 **Tauri v2 + React + Monaco Editor** 构建。

[English Version](./README.en.md)

## 特性

- **文件浏览器** -- 树形目录浏览，支持文件/文件夹增删改、重命名、固定常用目录
- **多标签编辑** -- 基于 Monaco Editor（VS Code 内核），支持多标签页、分栏（左右分屏）编辑
- **语法高亮** -- 内置数十种语言语法高亮
- **集成终端** -- 内嵌 xterm 终端，支持多终端标签页，跟随工作目录
- **Git 集成** -- 查看分支、暂存/未暂存/未跟踪文件、提交更改
- **图片预览** -- 内联预览，支持缩放
- **Word 文档预览** -- 预览 .docx/.docm/.dotx 等格式
- **Excel 编辑** -- 编辑 .xlsx/.xlsm：单元格与公式、多工作表（新增/改名/删除/拖拽排序）、区域选择与复制粘贴、插入删除行列、行高列宽拖拽与自适应、单元格格式（粗斜下划线/颜色/对齐/数字格式）与合并、排序筛选与查找替换、图片插入与剪贴板粘贴、保存前保真提示
- **Notebook 编辑** -- 打开 .ipynb：单元格列表（代码 / Markdown / Raw）、增删与上下移动、代码单元格按内容自适应高度、已有输出渲染（文本 / 图片 / HTML / 报错着色）、执行单元格（本机 Python，变量跨单元格保留，Ctrl+Enter / Shift+Enter、运行全部、中断与重启内核）、保存时保留未建模字段与原始写法
- **Markdown 预览** -- 实时渲染 + 代码高亮
- **十六进制查看** -- 查看二进制文件的十六进制表示
- **剪贴板表格** -- 粘贴表格数据自动转为 Markdown 表格
- **自动保存** -- 防丢失，自动保存编辑内容
- **设置面板** -- 自定义字体大小、Tab 缩进、最大打开标签数等
- **自定义 Monaco 主题** -- 暖心陶土色系主题
- **工作区持久化** -- 自动恢复上次打开的标签、目录状态、固定项

## 技术栈

| 层         | 技术                              |
| ---------- | --------------------------------- |
| 前端框架   | React 19 + TypeScript             |
| 编辑器引擎 | Monaco Editor (VS Code 内核)      |
| 桌面框架   | Tauri v2 (Rust 后端)              |
| 样式       | Tailwind CSS v4                   |
| 状态管理   | Zustand                           |
| 终端       | xterm.js + @xterm/addon-fit       |
| 构建工具   | Vite                              |

## 快速开始

```bash
# 安装依赖
pnpm install

# 桌面应用开发模式
pnpm tdev

# 浏览器预览（仅前端）
pnpm dev

# 构建
pnpm tbuild
```

> 注意：桌面端需要安装 [Rust](https://rustup.rs/) 和系统对应的 Tauri 编译环境。
